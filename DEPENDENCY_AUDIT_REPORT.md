## Environment

Copy `backend/.env.example` to `backend/.env` and set a local `SECRET_KEY`. Copy `frontend/.env.example` to `frontend/.env.local` only when the backend is not using the default API URL.

Tokens are optional for public GitHub/GitLab repositories and required for private repositories or authenticated API access.

## Validation

- Frontend TypeScript check passed before the final dependency reinstall attempt.
- Frontend lockfile-only install completed successfully; npm reported 23 existing audit findings (2 low, 4 moderate, 17 high). No `--force` upgrade was applied because it may introduce breaking changes.
- Frontend `npm ci` was blocked in the current machine by a locked `frontend/node_modules/@esbuild/win32-x64/esbuild.exe`; this is an environment lock, not a missing manifest dependency.

Generated ML files `backend/ml/model.pkl` and `backend/ml/scaler.pkl` are not committed. They are ignored by `*.pkl` and are regenerated by the ML service when a fresh clone starts without them.
